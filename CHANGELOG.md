# Changelog

## 0.1.0 — 2026-09-12

- Renamed the project to EasyGlobe.
- Added an interactive dotted globe with country-bound labels and animated language routes.
- Added source/target highlighting, route swapping, and selection reset.
- Added configurable branding, links, themes, colors, motion, and country content.
- Added local JSON settings import/export.
- Added macOS, Windows, and Linux launchers.
- Added GitHub Pages compatibility and bilingual project documentation.
- Added Apache License 2.0, project provenance, LangAlpha attribution, and third-party notices.
